1. 核对整个 `PDF/` 的导入覆盖、应用加载路径、有效文本质量与真实在线向量覆盖；改进页内分块和上下文组织，不能靠重复或更碎的块虚增语料。

## 执行方式与限制

在 CODEarts 当前会话内顺序实施，不依赖其他平台、不拆给子 Agent。沿用已有结构；先记录基线，再完成代码、相关回归测试与文档。不覆盖或提交当前未跟踪的私有数据与用户文件。

不得在线搜索或下载文献，不上传整本 PDF，不执行文档/模型生成的代码，不引入地化计算、复杂表格或云端 OCR。当前 `Source` 契约 0.2.0，未知元数据保持空值；需变更契约时同步版本、样例、迁移说明和测试。

mock provider 只用于自动测试，不是产品启动选项。所有引用绑定本次实际传入模型的证据；合法 ID 仍需核查是否支持对应结论。评估保留 dense-only 与 hybrid 同条件对照，背景解释单独核查，不算作成功文献回答。
