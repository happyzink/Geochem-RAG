## 目标与现状

目标流程：**中文问题 → 对齐中英文地学术语与检索意图 → 从英文原文检索证据 → 理解并用自然中文回答 → 保留英文证据及 PDF 页码供核查。**

本次只读检查发现：`retrieval.py` 已有 `_GEO_EXPANSIONS` 和 `expand_query`；当前 `retrieve_with_trace` 中 BM25 使用扩展文本，dense 分支仍嵌入原问题。`answering.py` 要求使用问题语言，但缺少术语一致、中文表达和译意忠实的具体约束。这是待验证的改进点，不表示已证明它们是全部原因，也不能把英文语料本身视为错误。

## 任务 A：先区分检索问题和表达问题

- [ ] 从实际知识库选择中文问题，检查正确英文证据是否已进入本次模型上下文。分别记录未召回、截断/上下文缺失、术语歧义、英文理解错误和中文表达生硬，不把所有问题归因于分块。
- [ ] 确认应用使用真实在线、多语言适用的嵌入模型，而不是 HashingEmbedder；查询与文档使用同一模型/空间，沿用既有缓存校验。模型适用性通过真实中英检索对照验证，不能仅看名称宣称有效。
- [ ] 先检查本轮已有改动是否解决相关问题，复用已实现功能；不要重复建设或大幅改写稳定模块。

## 任务 B：让中文问题找得到英文证据

主要文件：`src/geochem_rag/retrieval.py`、必要的 provider 调用适配、`tests/test_retrieval.py`；新增语言回归测试可放 `tests/test_cross_language.py`。

- [ ] 保留中文原问题，建立可追溯的英文检索表达与中英文关键词。查询转换只表达用户原意，不附加假定结论、不改变对象、时间、否定词、比较关系或范围。
- [ ] 优先改进现有术语词典：术语统一、别名和缩写明确区分；采用最长匹配/边界处理，避免“超基性”同时被短词“基性”误扩展。不是严格同义的概念不能无条件互换，例如 mantle source 与 mantle wedge；关联词可作为低权重召回线索，不替代原意。
- [ ] 对复杂中文问题，可通过 DeepSeek 生成一个简短英文检索问句和少量关键词，保留原问题。它仅用于检索，不是回答或证据；不翻译整本 PDF，不生成假定科学结果。API 失败必须可见，不伪装成转换成功；仍可用原问题及确定性词典继续检索，并记录降级原因。
- [ ] 比较“中文原问句”“英文等义问句”“双语检索并融合”三种查询策略。dense 保留原问题通道；需要英文通道时独立检索后融合，按 chunk ID 去重。BM25 使用英文领域词/短语补充；不要只将大量英文词串拼接后就宣称完成跨语言检索。
- [ ] 保护化学式、同位素符号、比值、缩写、地名、人名和年份，例如 Sr/Y、La/Yb、εHf(t)、U–Pb、MORB。未知缩写或地名含义不能靠猜测展开；必要时说明歧义。
- [ ] 检索轨迹能核查原问题、英文查询、采用策略与证据 ID；完整问题、查询和命中文本只存本地私有诊断目录，不提交公开仓库。查询转换会增加 API 数据发送、调用次数和延迟，按实际数据流同步使用说明。

## 任务 C：中文回答自然，科学含义忠实

主要文件：`src/geochem_rag/answering.py`、`tests/test_answering.py`；显示调整涉及 `app.py` 时沿用本轮简洁首页。

- [ ] 默认用中文回答中文问题，按中文科研交流习惯先给直接结论，再解释必要依据、机理与限制，不逐句硬译英文或机械复述每个证据块。
- [ ] 同一概念使用一致的中文术语，首次出现必要时给“中文名（英文术语/缩写）”；后文不反复堆英文。论文标题保留真实标题，不能把模型翻译的标题冒充来源元数据。
- [ ] 区分“提示/可能”“支持”“证实”等证据强度；英文中的 may、suggest、consistent with、not、except 以及条件限定不能在中文概括时丢失或加强。不要把相关关系改写成确定因果。
- [ ] 主回答可以基于英文证据用中文转述，引用仍指向实际传入模型的英文 chunk ID 与真实 PDF 页码，不要求原文必须有中文字面匹配。支持性检查关注语义是否成立，而不是语言是否一致。
- [ ] 在展开引用时保留英文原文片段；如提供中文释义，另标“中文释义”，明确是原文转述。中文释义不是新证据，不单独制造来源或页码，不能添加原文没有的结论。
- [ ] 通用知识补充仍独立标注“通用知识补充，未经本地文献核验”；回答中文化不得取消文献事实/补充知识的边界。具体论文事实、年代、数值、DOI 和页码缺证据时不补造。
- [ ] 专业词义不能确定、上下文不足或来源冲突时直接说明，不为了中文通顺擅自修补事实。地化表达的自然程度与科学含义需分别检查。

## 验证与交付

- [ ] 固定至少 10 对中文/英文等义问题，来源选当前本地语料并核对相关页码；覆盖缩写、术语同义表达、机理、比较、否定/条件和知识库未覆盖问题。评估题及参考证据默认私有，不猜造标准答案；尚未人工审核的标为草案，不当作已锁定成绩。
- [ ] 在相同语料、索引与模型条件下比较中英问题的相关页命中、引用正确性、中文译意与表达；中英问题不要求结果逐字相同，但都应覆盖支持回答的相关证据。
- [ ] 自动测试覆盖术语最长匹配、符号保留、英文查询不改变原问意、去重、转换错误、中文输出提示及英文证据 ID 的有效引用。回答自然度/科学译意用实际在线输出和人工核对，不能用简单中文字符比例代替。
- [ ] 使用自建英文测试证据检查：否定词不翻转、可能性不变成确定性、条件/数值不丢失、英文原文与中文释义关联一致。mock 只测流程，不报告真实在线质量。
