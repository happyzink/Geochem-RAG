# CODEarts 优先修复：点击设置报 StreamlitWidgetAlreadyInstantiatedError

用户已在实际页面遇到本错误。请在现有工作基础上优先修复，不覆盖其他已完成改动。

## 错误原因

`src/geochem_rag/app.py::_render_settings` 的三处写法都存在问题：

```python
st.session_state.retrieval_mode = st.selectbox(..., key="retrieval_mode")
st.session_state.top_k = st.slider(..., key="top_k")
st.session_state.allow_extended = st.toggle(..., key="allow_extended")
```

控件创建时已经通过 key 保存状态，外层赋值又修改同轮已创建控件的状态，引发异常。三处必须一起修复。

仅去掉外层赋值可以消除当次异常，但设置面板隐藏后，Streamlit 会清理未渲染控件的状态，可能导致用户选择丢失。因此采用独立的持久配置键和控件键，回调同步，不改 `_run_answer` 当前读取的配置键。

## 具体替换代码

在 `app.py` 中增加下面的回调，用下面的新函数替换当前 `_render_settings`。先读当前版本，保留其他 Agent 已完成的改动。代码中的 `retrieval_mode`、`top_k`、`allow_extended` 继续是问答使用的配置字段；`_settings_*` 只属于可隐藏的控件。

```python
def _save_setting(widget_key: str, setting_key: str) -> None:
    st.session_state[setting_key] = st.session_state[widget_key]


def _render_settings() -> None:
    st.subheader("设置")
    chat_cfg = getattr(st.session_state.chat, "config", None)
    embed_cfg = getattr(st.session_state.embedder, "config", None)
    if chat_cfg:
        st.caption(f"对话模型：`{chat_cfg.chat_model}`（{chat_cfg.base_url}）")
    if embed_cfg:
        st.caption(f"嵌入模型：`{embed_cfg.embedding_model}`（{embed_cfg.base_url}）")

    defaults = {
        "retrieval_mode": "hybrid",
        "top_k": 5,
        "allow_extended": True,
    }
    for setting_key, default in defaults.items():
        st.session_state.setdefault(setting_key, default)
        # Before each widget is created, restore its value from persistent config.
        st.session_state[f"_settings_{setting_key}"] = st.session_state[setting_key]

    st.selectbox(
        "检索方式",
        ["hybrid", "dense_only", "bm25_only"],
        key="_settings_retrieval_mode",
        on_change=_save_setting,
        args=("_settings_retrieval_mode", "retrieval_mode"),
    )
    st.slider(
        "证据块数（top-k）",
        min_value=1,
        max_value=10,
        key="_settings_top_k",
        on_change=_save_setting,
        args=("_settings_top_k", "top_k"),
    )
    st.toggle(
        "允许通用背景补充（未经本地文献核验）",
        key="_settings_allow_extended",
        on_change=_save_setting,
        args=("_settings_allow_extended", "allow_extended"),
    )
```

该代码是待 CODEarts 实施的具体方案，不表示产品文件已经修复。
